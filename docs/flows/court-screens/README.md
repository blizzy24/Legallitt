# Court screen comparisons — 14 November 2026

All captures use new synthetic cases in the isolated local application database. No real case was changed. The comparison includes the complete captured screen, scaled to fit; open the original for full resolution. The overnight answers override drawn prices, phone/call controls, payment timing and hearing payouts. Test checkout is explicit rather than presenting a payment QR as real. Admin screens use the existing panel style (§9.2).

The same engine renders both court levels. Case type, court selector, prices, deadlines and reference prefix come from their own configuration. Labels and empty states omit unavailable values. Legal policy copy remains awaiting the client; the linked pages say so.
