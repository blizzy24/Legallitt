Actual browser captures from the isolated local acceptance database; all cases are newly labelled synthetic data. The 60-point answers override drawn fixed tier prices, independent advocate end-call controls and repeated KYC. Test calls transmit no media. Test checkout and preliminary AI output are labelled. Missing configuration and real empty profiles are not filled with fixtures. Admin screens use the existing panel style (architecture §9.2).
