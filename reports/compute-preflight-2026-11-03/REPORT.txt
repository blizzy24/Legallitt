NAT and endpoint findings

infra/src/stack.ts unconditionally creates Nat0 and NatIp0. NatMode accepts only
single or per_az. per_az additionally creates Nat1 and NatIp1. Fargate tasks have
no public IP and use the private subnet default routes through NAT.

One NAT plus its own IPv4 costs USD 44.53/month (approximately INR 4,225 before
GST or INR 4,985 with GST), before per-GB NAT processing. This is already above
the approximately INR 3,000 assumption. A second NAT adds the same fixed amount.

Replacing NAT with only S3, Secrets Manager and Bedrock endpoints would strand
other dependencies: private ECR image pulls need ecr.api and ecr.dkr plus S3;
awslogs needs Logs; authentication needs Cognito. The app also retrieves Cognito
JWT verification keys, whose private retrieval path would need verification.
Gemini calls Google's public API and cannot be reached through AWS endpoints.

Mumbai's endpoint-service API confirms Secrets Manager, Bedrock Runtime,
Cognito IdP, ECR API/Docker, Logs and SQS endpoints exist. An S3 gateway endpoint
has no endpoint hourly charge. Interface endpoints do: USD 0.013 per endpoint
per AZ per hour here, plus data processing.

Five interface services for the basic current AWS-only runtime (Secrets Manager,
ECR API, ECR Docker, Logs, Cognito) cost USD 47.45/month even in ONE AZ, excluding
S3 gateway routing, traffic and verification of JWT-key access. Adding Bedrock
Runtime and SQS brings that to USD 66.43/month. Two AZs double those endpoint
hourly costs. These are illustrations, not tested replacement topologies. They
are not a saving over the single NAT and do not clear the total budget gate.
SQS is provisioned by this skeleton; its endpoint is only needed when a private
consumer/producer actually uses it. Bedrock is likewise optional while AI is
simulated. Neither optional dependency was used to inflate the five-endpoint
baseline.

No NAT or endpoint code was changed: the requested three endpoints are
insufficient, the broader endpoint option exceeds the budget, and the instruction
explicitly says to stop on that result. Public-addressed Fargate/another outbound
topology has not been substituted without a decision on that architecture.
