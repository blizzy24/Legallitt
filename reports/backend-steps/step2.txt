Step 2 — CDK foundation

LegalittDev and LegalittProd synthesize separate stacks, both in ap-south-1 and
using the same CDK_DEFAULT_ACCOUNT (or CloudFormation's account token). No AWS
credentials/account lookup, bootstrap or deployment was performed.

Each stack has public/private subnets across two AZs (ALB and RDS subnet-group
requirements), VPC routes/NAT, HTTPS ALB, Fargate service, private Postgres 16,
SSE-KMS document bucket, generated database credential secret, SQS, runtime and
execution roles with permission boundaries, CloudWatch logs and an ECR repository.
RDS is single-AZ in dev and Multi-AZ in prod as required before launch.
Runtime allowlists reference only that stage's resources; dev additionally denies
prod-tagged resources and service-specific prod-name ARN patterns. The only
unscoped allow is ECR GetAuthorizationToken; image access is repository-scoped.
These boundaries cover the created runtime roles, not an external deployment
operator or pre-existing account roles. Deployment IAM setup remains outside this
synth-only phase.

Unspecified values left as required parameters, with no fabricated defaults:
VPC/subnet CIDRs, NAT topology (single/per-AZ), DB instance/storage/16.x version,
task CPU/memory/count, API port/image tag and ACM certificate ARN.
No retention duration is invented. Persistent data/key/log/repository resources
are retained on stack removal; database deletion protection is enabled. Application
retention/deletion policies remain the client's §8 question.

All taggable resources carry environment/application tags. AWS cannot tag routes,
associations, inline/bucket/managed policies, listeners and KMS aliases through
these CloudFormation resource types; these carry environment metadata and have
tagged parents. No claim is made that metadata is an AWS resource tag.

Validation: six template/security/schema tests passed; cdk synth --no-lookups
passed with strict CloudFormation validation and zero findings; all workspace
typechecks passed. Resource counts and required parameters: step2-synth.json.
